# Professor Demonstration Guide

## 1. Project Introduction
Explain the objective: detecting fraudulent financial transactions using machine learning and MLOps.

## 2. Dataset
Show the PaySim dataset, 200,000-row sample and class imbalance.

## 3. Data Pipeline
Demonstrate ingestion, validation, preprocessing and feature engineering.

## 4. Model Training
Explain Logistic Regression, Random Forest and XGBoost comparison. Show the recorded evaluation metrics and XGBoost champion selection.

## 5. Feature Store and Model Registry
Show Feast feature retrieval and the MLflow registered champion model.

## 6. Streaming and Database
Demonstrate Kafka topics and PostgreSQL transaction and monitoring tables.

## 7. API Deployment
Open the FastAPI health endpoint and demonstrate a prediction request.

## 8. Monitoring
Show Prometheus metrics, Grafana dashboards and the recorded drift evaluation.

## 9. Cloud Storage and CI/CD
Show the AWS S3 bucket, DVC remote and successful GitHub Actions workflow.

## 10. Conclusion
Summarize the completed pipeline, technologies, test results and project limitations.

## Important
Use actual project outputs and screenshots during the demonstration. Do not present synthetic dataset results as real banking performance.
